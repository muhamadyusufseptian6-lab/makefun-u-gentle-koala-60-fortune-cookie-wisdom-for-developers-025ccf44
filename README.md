> "The code you wrote at midnight will review you in the morning."

Every developer knows the feeling: the clever shortcut that made perfect sense at midnight looks like a stranger's prank by morning standup. This fortune cookie says the quiet part out loud — your future self is the strictest code reviewer you will ever meet, and the review always arrives with the sunrise, whether you asked for it or not.

Run it yourself:

```sh
mkdir -p /tmp/fortune-out
MAKEFUN_OUTPUT_DIR=/tmp/fortune-out node main.ts
cat /tmp/fortune-out/entry.txt
```
